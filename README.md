Entry for **Everyday Wonder: Two Days to Find the Line** — exactly one sentence, at most 200 characters, making a small everyday moment strange and new.

> My reflection in the elevator mirror blinked a half-second late, then smiled like it had been waiting all day for me to notice.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/everyday-wonder-out node main.ts
```

This writes the single sentence to `entry.txt` in the output directory only, with no trailing newline, then reads it back and verifies it matches byte-for-byte.
